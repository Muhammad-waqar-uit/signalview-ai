# SignalView AI landing page

Next.js 14 (App Router).

    npm install
    npm run dev

- Glass nav collapses to a small pill on scroll; tap the pill to open it again.
- Headline rises in word by word; the sky backdrop drifts and moves slightly slower than the page.
- The sky is built from CSS (gradients, blurred clouds, leaf shapes, bokeh). To use your own photo,
  put it in `public/` and set it as the background of `.bd-sky` in `app/globals.css`.
